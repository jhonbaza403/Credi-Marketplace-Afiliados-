# Credi Marketplace
# Architecture Documentation


## 1. Overview

Credi Marketplace is a global commerce platform built with:

- Next.js 16.3
- React 19.2
- TypeScript
- Node.js 24
- Supabase
- PostgreSQL


The platform supports:

- Marketplace commerce
- Affiliate system
- B2B transactions
- Payments
- Orders
- Inventory
- AI services
- Notifications
