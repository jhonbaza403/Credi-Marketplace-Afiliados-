# Credi Marketplace

Production-oriented marketplace platform built with Next.js 16, React 19, TypeScript, Tailwind CSS 4, Supabase and Vercel.

## Runtime

- Node.js 24.20.0 LTS
- npm 11.x
- Next.js 16.3.3
- React 19.2.8
- TypeScript 7.0.2
- Tailwind CSS 4.3.3

## Installation

Use Node 24.20.0, then generate the lockfile from this package manifest:

```bash
nvm use
npm install
npm ci
```

`package-lock.json` is intentionally generated by npm from the authoritative `package.json`; do not hand-edit it.

## Quality gate

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
npm run security:audit
```

CI must pass before production deployment.

## Vercel

The repository root must contain `package.json`. Do not set a nested Root Directory unless the repository itself is intentionally nested.

Required production environment variables are documented in `.env.example`.
